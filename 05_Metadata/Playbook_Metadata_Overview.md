# Metadata Overview
*Index of the decision frameworks used across the platform.*

The core principles and philosophies live in one place: the [README](../README.md) (Core Principles and Core Philosophies).
This folder holds the frameworks that put them into practice.

---

| Framework | Use it when | Doc |
| :--- | :--- | :--- |
| **Red / Green Logic** | Deciding whether a change, deploy, or access request may proceed | [RedGreen_Logic.md](RedGreen_Logic.md) |
| **Two Sides of the Coin** | Weighing short-term speed against long-term flow | [Two_Sides_of_the_Coin.md](Two_Sides_of_the_Coin.md) |
| **Least Privilege** | Granting or reviewing any identity's access | [Least_Privilege_Checklist.md](Least_Privilege_Checklist.md) |

---

## How They Connect

1. **Two Sides of the Coin** frames the trade-off.
2. **Red / Green** turns it into a go / no-go signal against the standards.
3. **Least Privilege** is the default Red condition for anything touching identity or access.
