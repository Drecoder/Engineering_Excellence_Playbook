# Prevent Drift

At the start of every task or prompt, use the authoritative [Drift Prevention rule](../../../00_UniversalStandards/09_Reuse_and_DRY.md#drift-prevention). Keep it active during reasoning, planning, execution, and retrospective assessment.

Apply it silently. Preserve existing authority, API contracts, architecture, and governance. Report actual blockers through the existing handoff and escalation paths.
